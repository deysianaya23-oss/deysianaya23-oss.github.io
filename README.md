# DeyLab — Deysi Anaya

An original, editable and responsive interactive portfolio built with HTML, CSS and vanilla JavaScript. Designed for static hosting on GitHub Pages.

## Files
- `index.html`: editorial portfolio, twelve project stories and seven interactive learning modules.
- `style.css`: bespoke black / white / lilac styling with original line-art flowers as SVG. Google Fonts enhance appearance, but system fallbacks are included.
- `script.js`: synthetic dashboard, Go/No-Go, gaze explorer, Excel cleaning simulator, MOVE points and navigation.
- `hr-suite.html`: employee self-service / HR manager / digital workflow linked demo. Maintains user interactions through local browser storage.

## Publish to GitHub Pages
1. Create a **public** repository `deysianaya23-oss.github.io` under GitHub account `deysianaya23-oss`, or use the existing one.
2. Upload the **four files inside this folder** to the repository root (do not upload the ZIP as a single file).
3. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Website will appear at `https://deysianaya23-oss.github.io` once Pages finishes deployment.

## How to test locally
Open `index.html` in a modern browser. All interactions use client-side JavaScript; no server or build step is needed.

## Ethics and portfolio accuracy
- All dashboards, records and visualizations are synthetic, and do not portray Mondelēz or any other employer's actual data.
- The eye-tracking exploration is a fictional illustration; the user's real research relied on publicly available data, not self-collected recordings.
- The original Go/No-Go design was implemented separately in PsychoPy; the browser version is a recreation, not a clinical tool.
- Demo workflows are not real Microsoft integrations, and no payroll or health calculations should be used for real decisions.
- Power BI actual reports can be linked later **only if created with approved public/synthetic data and intended for public access**. Do not embed internal dashboards.
